# Resumindo Textos com IA

Este projeto utiliza o Google Gemini para resumir textos sem remover os detalhes mais importantes ou gerar informações falsas. O programa foi escrito em Python e a interface foi criada com o Streamlit, um framework que cria aplicações web baseadas em Python.

## Como Instalar

Para utilizar o resumidor é preciso possuir uma chave de API do Google Gemini, você pode obtê-la gratuitamente no [Google AI Studio](https://aistudio.google.com/). Em seguida, crie um arquivo ```.env``` e crie uma variável de ambiente para armazenar a chave.

As bibliotecas necessárias podem ser encontradas [aqui](requirements.txt).
